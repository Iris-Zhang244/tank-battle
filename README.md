# 坦克大战 Tank Battle

经典的 2D 坦克大战游戏，纯 HTML5 Canvas + JavaScript 实现，单文件、零依赖，打开 `index.html` 即玩。

## 在线试玩

直接用浏览器打开 `index.html` 即可，无需服务器。

## 操作方式

| 按键 | 功能 |
|------|------|
| `W` / `↑` | 向上移动 |
| `S` / `↓` | 向下移动 |
| `A` / `←` | 向左移动 |
| `D` / `→` | 向右移动 |
| `J` / `空格` | 射击 |
| `P` | 暂停 / 继续 |
| `回车` | 确认开始 |

## 游戏规则

- 保卫地图底部的金色 ★ 基地，基地被摧毁即失败
- 消灭当前关卡所有敌方坦克即可进入下一关
- 砖墙可被子弹摧毁，钢墙不可摧毁（第 3 关后玩家子弹可破钢墙）
- 灰色装甲坦克需要 3 发子弹才能击毁，击毁得 300 分；普通坦克 100 分
- 关卡越高，敌人数量越多、速度越快

## 本地运行

```bash
# 直接打开
start index.html

# 或者启动一个本地服务器
python -m http.server 8000
# 然后访问 http://localhost:8000
```

## 技术说明

- 单文件实现，无外部依赖
- 使用 HTML5 Canvas 渲染
- 音效由 WebAudio API 实时合成，无音频文件
- 敌方坦克 AI：随机游走 + 追踪玩家/基地倾向
